# P.I.X.E.L

Student PBL frontend (SMIT CSE, 2024–2028). Single page for uploading **images and videos** to a FastAPI analyser.

## Run locally

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Start your FastAPI app on port 8000 (see `docs/CONNECT_BACKEND.md`).
